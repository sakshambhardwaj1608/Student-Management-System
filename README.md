Student Management System

A simple console-based Student Management System developed using C++.

Features
Add student records
Display all student records
Search student by roll number
Delete student records
Store student data using file handling
Technologies Used
C++
Object-Oriented Programming (OOP)
File Handling
Student Information

The system stores the following information:

Roll Number 
Name 
Course  
Marks 


How to Run
Download or clone the project.
Open the .cpp file in a C++ compiler such as Code::Blocks, VS Code, or Dev-C++.
Compile and run the program.
Use the menu to manage student records.
File Handling

The program uses students.txt to save student records so that the data can be accessed again when the program is run.
